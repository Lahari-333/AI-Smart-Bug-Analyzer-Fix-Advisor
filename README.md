# 🤖 AI Smart Bug Analyzer & Fix Advisor

An AI-powered multi-agent system that automatically analyzes software bugs, detects duplicates, identifies root causes, retrieves similar historical bugs, and recommends fixes.

## 🚀 Features

- 🐞 Bug submission through Streamlit UI
- 🎯 Bug triage: severity, priority, and component
- 🔍 Stack-trace and exception analysis
- 🔄 Duplicate bug detection using similarity search
- 🧠 Root-cause analysis
- 📚 Historical bug retrieval using FAISS
- 💡 Fix recommendations and preventive measures
- 📊 Defect pattern analytics
- 🌱 Knowledge-base growth using resolved bugs
- 🧪 End-to-end testing and agent evaluation
